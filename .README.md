# Small Hands (V1.0) 🤝

**Bridging the gap between Need and Help.**

Small Hands is a real-time humanitarian aid platform that connects citizens spotting distress with nearby NGOs capable of providing immediate relief.

![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![Stack](https://img.shields.io/badge/Stack-MERN-yellow)

## 🌟 Key Features

### 📡 Real-Time Live Console

- **Interactive Maps:** Powered by Leaflet.js, showing distress signals in real-time.
- **Socket.io Integration:** NGOs receive instant "Red Alerts" without refreshing the page.
- **Geolocation:** Auto-detects user location to show relevant nearby cases.

### 🛡️ Role-Based Access Control

- **Citizens (Reporters):** Post anonymous reports, upload evidence, earn Karma Points.
- **NGOs:** Must be **Verified** by Admins. Can view the live map, claim cases, and upload proof of resolution to boost their Impact Score.
- **Super Admin:** "God Mode" dashboard to verify NGOs, ban spammers, and moderate content.

### 🏆 Gamification

- **Leaderboard:** Tracks top-performing Citizens and NGOs.
- **Karma System:** Validated reports earn points; Spam reports lead to bans.

## 🛠️ Tech Stack

**Frontend:**

- React.js (Vite)
- Tailwind CSS v4 (Styling)
- React Leaflet (Maps)
- Socket.io Client (Real-time data)
- React Hook Form + Zod (Validation)

**Backend:**

- Node.js & Express.js
- MongoDB Atlas (Database) & Mongoose
- Socket.io (WebSockets)
- JWT (Authentication)
- Cloudinary (Image Storage)

## 🚀 Installation & Setup

### Prerequisites

- Node.js (v18+)
- MongoDB Atlas Account
- Cloudinary Account

### 1. Clone the Repository

```bash
git clone [https://github.com/your-username/small-hands.git](https://github.com/your-username/small-hands.git)
cd small-hands

2. Backend Setup
Bash

cd server
npm install
Create a .env file in /server:

Code snippet

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_super_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_key
CLOUDINARY_API_SECRET=your_secret
CLIENT_URL=http://localhost:5173
Start the server:

Bash

npm start
3. Frontend Setup
Bash

cd client
npm install
Create a .env file in /client:

Code snippet

VITE_API_URL=http://localhost:5000/api
Start the client:

Bash

npm run dev
```
